# CSIViewer

- Software para el control remoto tipo TeamViewer
- Consta de...
    - CSIViewer Servidor (El servidor)
    - CSIViewer Host (El programa que hace de Host, solo sirve conexiones)
    - CSIViewer Cliente (El que puede tomar el control de los hosts)

- Software desarrollado en .NET 10 con C# y WinUI 3.0
